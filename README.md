# Credit Risk Predictive Modeling & Portfolio Analytics (Saviour Project)

## Project Overview
This project presents an end-to-end predictive classification and business intelligence solution to manage credit default risk. It bridges technical machine learning engineering with executive-level strategic reporting, designed directly to help a Board of Directors make data-driven lending decisions.

## Project Deliverables
*   **Python Predictive Modeling (`.py` / `.ipynb`):** The core machine learning engine built to clean data, handle extreme class imbalance using SMOTE, and train predictive models (Random Forest, XGBoost).
*   **Interactive Power-BI Dashboards (`.pbix`):** A dynamic, executive-ready dashboard translating model predictions and portfolio risk profiles into interactive, scannable visual insights.
*   **Executive Board Presentation (`.pptx`):** A high-level strategic report designed specifically for the Board of Directors, translating algorithmic metrics into clear business risks and mitigation strategies.

## Methodology & Analytical Highlights
*   **Data Balancing & Modeling:** Applied SMOTE to address severe dataset imbalance, optimizing the classification model for high Recall (minimizing undetected defaults) and AUC-ROC performance.
*   **Explainable AI (XAI):** Utilized SHAP frameworks to ensure that model outputs are transparent, fair, and auditable for credit risk evaluations.
*   **Data Translation:** Synthesized technical accuracy with business utility, designing interactive dashboards and executive summaries for C-suite decision-makers.
